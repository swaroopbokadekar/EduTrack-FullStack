# 🎓 EduTrack Student Management System

A Full-Stack application built with **React**, **Spring Boot**, and **MySQL**.

## 🚀 Features
* **Authentication:** Secure login for administrators.
* **Student Management:** Register, view, and delete student records.
* **Attendance:** Track daily attendance (Present/Absent).
* **Performance:** Assign and view subject-wise marks.

## 🛠️ Setup Instructions

### 1. Database
* Open MySQL Workbench.
* Run the `edutrack_dump.sql` script found in this repository to create the schema and test data.

### 2. Backend (Spring Boot)
* Import the `edutrack-backend` folder into Eclipse as an **Existing Maven Project**.
* Update `src/main/resources/application.properties` with your MySQL password.
* Run the application.

### 3. Frontend (React)
* Navigate to `edutrack-frontend` in your terminal.
* Run `npm install` to download dependencies.
* Run `npm start` to launch the dashboard.
